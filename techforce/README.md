# TechForce — On-demand Technical Workforce Platform

## Product thesis
파트너/영업이 고객 프로젝트에 필요한 기술역량을 필요한 만큼 구매하고, 플랫폼이 AI + 검증된 전문가 + 표준 Runbook으로 업무를 완수하는 B2B 기술인력 플랫폼.

## Core flow
Sales Request → Scope & Price → Approval/Payment → AI Triage → Expert Matching → Execution → QA → Evidence → Completion

## Personas
- Sales: 고객 요구를 등록하고 필요한 기술지원을 구매
- Partner Admin: 비용/승인/프로젝트 현황 관리
- Expert: 배정된 작업 수행
- TechForce Ops: 매칭/에스컬레이션/품질관리
- Customer Viewer: 결과/증적 확인

## Service catalog
- Solution Architect
- Infrastructure Engineer
- Package Engineer
- DBA
- Kubernetes Engineer
- Operations / Customer Support

## Commercial model
- Fixed task
- Hourly
- Daily
- Priority surcharge
- Monthly managed support
- Partner credit / prepaid balance

## Key differentiator
사람만 연결하지 않는다.
Expert + AI Copilot + Runbook + Preflight + Evidence + QA를 묶어 동일 품질의 '서비스 상품'으로 제공한다.

## MVP
1. Service catalog
2. New resource request
3. Auto scoping & estimated price
4. Approval / payment state
5. AI triage
6. Expert matching
7. Workboard
8. QA / evidence checklist
9. Completion / acceptance
10. Partner spend & SLA dashboard
