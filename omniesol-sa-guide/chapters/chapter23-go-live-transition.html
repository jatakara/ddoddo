23.13 Go-Live의 단계적 승인

Go-Live는 단일 배포 명령이 아니라 업무 서비스 전환에 관한 의사결정이다. 기술 설치, 데이터 이관, 사용자 공지, 접속 전환, 롤백과 운영 수용이 함께 준비되어야 한다.

Go-Live 이후의 변경은 이미 고객에게 영향을 주는 운영 변경이다. 비상 롤백을 포함해 변경 창과 승인권자를 사전에 지정한다.

23.14 Go/No-Go 결정 Matrix

필수 게이트GO 예NO-GO 예
기능핵심 업무 시나리오 Pass필수 거래·인증 실패
성능합의한 p95·오류율 충족업무 피크에서 반복 실패
보안고위험 노출·권한 문제 해결미승인 외부 API 접근
복구복원 및 RTO/RPO 실증백업만 있고 복원 미검증
운영모니터링·Runbook·담당자 준비장애 책임자·에스컬레이션 없음
롤백복귀 절차·데이터 호환성 검증되돌릴 수 없는 DB 변경 미검토

결정 회의는 단순 다수결이 아니다. 필수 보안·법적·계약적 요구조건은 비용이나 일정상 이익으로 상쇄할 수 없다.

23.15 Cutover Runbook과 원복 기준

Cutover는 기존 서비스에서 신규 서비스로 사용자의 업무 경로를 바꾸는 작업이다. DNS TTL, 세션, 인증서, DB 데이터 이관, 외부 연계 재접속, 캐시와 비동기 메시지까지 고려한다.

T-7d  : 변경 범위·업무 공지·연락망 확정
T-1d  : 사전 백업·복원 가능성·구성 동결 확인
T-0   : 변경 승인, 기준선 지표 캡처
T+15m : DNS/TLS/Proxy 및 주요 API 점검
T+30m : ERP 거래·UC·모바일 업무 검증
T+60m : p95·오류율·DB 대기·큐·로그 비교
T+90m : Go/No-Go 재판정 및 운영 인계
Rollback trigger: 핵심 업무 실패, 보안 위험, 데이터 불일치
Rollback owner: 변경 승인권자 / 실행 담당 지정
데이터 롤백

애플리케이션 패키지를 이전 버전으로 돌려도 DB 스키마와 이미 생성된 거래 데이터가 자동으로 복구되지는 않는다. 사전 이관 검증·양방향 호환·복원 시점·데이터 재처리 계획을 별도로 수립한다.

23.16 Hypercare와 SLO 기반 안정화

Hypercare는 신규 운영 전환 직후 집중 지원 기간이다. 기간은 프로젝트의 복잡도와 계약에 따라 다르며, 며칠 또는 몇 주라는 고정 수치보다 종료 조건이 중요하다.

지표관측 방법종료 판단 예
업무 성공률합성 트랜잭션·업무 로그합의한 SLO 충족
응답 성능p95/p99, 배치 피크검수 기준선 대비 허용 범위
서비스 오류5xx·인증 실패·UC 연결 끊김중대 반복 장애 없음
인프라 여유DB Pool, CPU/메모리, 스토리지성장·N+1 여유 확인
운영 대응MTTA/MTTR, Runbook 성공운영팀 독자 대응 가능
보안/복구권한·예외·백업/복원 상태미해결 중대 위험 없음

Hypercare 중에는 관측 데이터의 임계치와 노이즈를 보정하되, 장애를 숨기기 위해 경보를 무분별하게 끄지 않는다. 경보 변경도 승인과 기록이 필요하다.

23.17 운영 전환의 확장성·보안 Trade-off

선택장점위험/보완
일괄 Cutover절차 단순, 기간 짧음장애 시 영향 큼; 검증된 롤백 필수
단계적 사용자 전환영향 제한, 비교 검증 가능세션·DB 호환성과 라우팅 복잡
Blue/Green빠른 트래픽 복귀 가능인프라 비용 증가, DB 롤백 별도
Canary점진적 오류 탐지사용자 분류·메트릭·보안 정책 일관성 필요

분산 트래픽 전환 방식이 항상 좋은 것은 아니다. 업무 거래의 중복 처리, 스키마 호환성, 라이선스와 보안 정책이 이를 허용하는지 먼저 확인한다.

  • 보안: 관리자 계정·API·방화벽 예외가 전환 후에도 최소 권한인지 검증한다.
  • 확장성: 신규 트래픽의 p95·DB 연결 풀·K8s N+1·스토리지 증가율을 검증한다.
  • 기술 부채: 임시 DNS/hosts, 수동 작업, 임시 Proxy 예외를 종료 백로그에 기록한다.

23.18 최종 운영 수용과 다음 장

운영 수용은 구축팀과 운영팀의 서명만으로 완성되지 않는다. 실제 서비스 Owner가 목표 업무를 검증하고, 운영팀이 장애 대응과 복구 책임을 수행할 수 있어야 한다.

최종 항목증거승인 역할
FAT/SAT 완료추적 Matrix·결함 종료품질·업무 담당
성능·SLO시험 및 Hypercare 리포트서비스 Owner
보안·접근인가·노출·예외 점검보안 책임자
복구·DR복원 결과·RTO/RPODBA·운영 책임자
운영 인수Runbook·RACI·실습 결과운영 책임자
