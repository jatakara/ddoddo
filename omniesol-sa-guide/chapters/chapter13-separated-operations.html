13.9 독립 용량 산정과 확장

ERP는 TPS/RPS, 마감 배치, SQL 대기, DB I/O가 중요하다. UC는 동시 세션, 장기 연결, 메시지·메일·첨부·검색 부하를 평가한다. 서비스별 피크 시간, p95/p99, 오류율, 성장률을 독립적으로 수집한다.

구분ERP ZoneUC Zone
주요 부하업무 트랜잭션·DB·배치동시 연결·실시간 처리·파일
주요 병목DB Lock·I/O, WAS 스레드·풀Pod CPU·메모리, Ingress, 저장소
확장WAS 증설·DB 튜닝·지원 HAPod/Worker 증설·큐·스토리지 검토
검증마감·대량 조회 중 응답시간로그인·실시간 연결·업로드 혼합
가상 성능 시험 예시 (제품 공식 권장값 아님)
ERP AP 2대, 각 120 RPS에서 목표 SLO 충족
정상 처리 가능량 = 240 RPS
1대 장애 시 = 120 RPS
요구 피크 = 140 RPS → 장애 시 용량 부족
⇒ AP 3대 또는 처리량 개선·피크 완화 필요

UC Worker 3대, 각 60 업무단위 처리 가능
1대 장애 시 120 업무단위
요구 피크 100 → 계산상 가능
단, Pod 배치·Ingress·DB·스토리지 병목은 별도 검증

위 업무단위는 실제 부하 시험에서 정의한 유효 처리량이다. 단순 vCPU 합계나 노드 수만으로 N+1을 판정하지 않는다. 공통 계층의 용량도 함께 검증한다.

13.10 HA·백업·DR

영역ERPUC공통 의존성
HAWEB/WAS 이중화, 지원 DB HAWorker/Ingress, 상태 저장 서비스 보호LB·DNS·SSO 단일 장애점
백업DB 정합성, 시점 복구, 첨부 데이터DB·파일·메일 데이터 복원 순서백업 관리 계정·저장소
DR업무별 RPO/RTO, 전환 절차세션 재연결, 큐 재처리, 데이터 일관성DNS TTL·인증서·접속 경로

RPO는 허용 데이터 손실 범위, RTO는 목표 복구 시간이다. HA는 논리 오류, 랜섬웨어, 지역 장애를 대비하는 백업·DR을 대체하지 않는다. 스냅샷만 보유하고 복원 시험을 하지 않는 것은 복구 가능성을 증명하지 못한다.

13.11 TCO와 기술적 부채

비용은 서버 구매비뿐 아니라 3~5년 동안의 OS·DB·가상화 라이선스, 유지보수, 전력, 공간, 백업·DR, 운영 인력, 장애 대응과 확장 비용을 합산한다.

TCO = 초기 컴퓨트·스토리지·네트워크
    + 라이선스·유지보수·전력·공간
    + 백업·DR·운영 인력
    + 변경·장애 대응·확장 비용
분리형 이점비용/부채완화책
장애 격리중복 장비와 여유 용량업무 중단 손실과 비교
변경 독립성정책·배포 경로 증가IaC·공통 템플릿
성능 예측성낮은 평균 자원 사용률계측 기반 계획 증설
보안 경계방화벽 예외·계정 관리 증가정책 코드화·정기 감사

동일 설정의 수작업 복제, 서비스 간 변경 승인 누락, 복원 절차 부재, 지표 불일치는 분리형에서 쉽게 누적되는 기술적 부채다.

13.12 장애 시험과 Go/No-Go

시험합격 기준증빙
ERP WAS 1대 장애ERP 목표 SLO/복구 시간 충족, UC 영향 없음양쪽 p95·오류율
UC Worker 1대 장애UC 복구, ERP 영향 없음Pod 이벤트·사용자 여정
공통 DNS/SSO 장애예상한 영향 범위·복구 절차 일치의존성·복구 기록
ERP 마감 + UC 혼합 부하각 서비스 피크 SLO 충족APM·DB·Ingress 지표
DB/파일 복원서비스별 RPO/RTO·정합성 충족복원 시험·승인 기록
영역 간 접근 통제비허용 통신 차단, 필수 연계 허용정책·접근 기록

운영 승인 체크리스트

  • □ ERP/UC 실행 위치, DB, 백업, 관리 책임을 명시했다.
  • □ 공통 DNS·LB·SSO·스토리지 장애 영향을 기록했다.
  • □ 내부/외부 접속 및 연계 API 경로를 검증했다.
  • □ 제품 지원 구성·라이선스·패치 호환성을 확인했다.
  • □ 서비스별 SLO·RPO·RTO와 장애 시 용량을 검증했다.
  • □ 최소 권한·인증서·비밀정보·운영 접근을 점검했다.
  • □ RACI, 변경 승인, 원복, 복구 시험 결과가 있다.

No-Go: 미지원 배포, 비허용 영역 간 접근, 장애 시 필수 용량 부족, 복원 실패, 책임 주체 미확정. 예외 승인은 위험 수용자·기한·완화책을 문서화한다.
