실제 OmniEsol 설치 명령 또는 지원 사양이 아니다. 제품 공식 지원 문서, 보안 정책 및 변경 승인을 우선한다. 모든 주소와 수치는 교육용 예시다.

34.13 멱등성과 체크포인트

멱등성은 같은 목표 상태를 반복 적용해도 불필요한 변경을 추가하지 않는 성질이다. 성공 마커만 믿지 말고 실제 상태를 검사한다. DB 생성, 스키마 마이그레이션 등 비멱등 작업은 공급자의 재개 기능과 작업 식별자를 사용한다.

inspect(target)
if desired_state_verified: record_verified()
elif unknown_or_conflicting: block_and_escalate()
else:
    require_valid_approval()
    apply_reviewed_adapter()
    verify_postconditions()
    persist_checkpoint()

의사코드이며 운영 실행 스크립트가 아니다. 체크포인트에는 작업 ID, 입력 digest, 대상 식별자, 관측 결과, 시간, 승인 참조를 남긴다.

34.14 실패 분류와 재시도

실패처리
일시적 전송 오류부분 파일 상태 확인 후 제한된 재시도
인증·호스트 키 오류중단 및 담당자 확인
SSH 단절 중 설치UNKNOWN, 원격 프로세스 및 결과 조사
디스크 부족환경 개선 후 readiness 재검증
DB 스키마 실패공식 복구 절차 및 DBA 승인

재시도는 횟수와 시간 상한, 지수 백오프 및 jitter를 둔다. 성공 여부가 모호한 변경은 자동 재시도 대상에서 제외한다.

34.15 롤백과 보상 작업

롤백은 이전 상태로 복귀하는 것이고 보상 작업은 발생한 부작용을 별도의 작업으로 해소하는 것이다. 설정 파일은 승인된 백업으로 되돌릴 수 있지만 데이터베이스 스키마 변경은 파일 복원만으로 해결되지 않는다.

변경복구 방향
WEB 설정검증된 이전 설정 복원 및 재검증
이미지 배포호환성 검증 후 이전 digest 배포
DB 변경공식 다운그레이드 또는 검증된 복구 계획
디스크 초기화자동 원복 불가, 사전 승인 및 백업 필수

복구는 데이터 손실과 다른 시스템의 정합성에 영향을 줄 수 있다. 자동 롤백은 사전에 검증되고 승인된 범위로 제한한다.

34.16 현장 실습: 연결 단절 뒤 재개

격리된 실습 환경에서 ERP WAS 설치 도중 SSH 연결을 끊는다. 실행기는 상태를 UNKNOWN으로 기록하고 WEB 설치를 차단한다. 재접속 후 설치 도구 로그와 프로세스, 대상 버전, 구성 검증 결과를 확인한다.

설치가 완료됐다면 사후 검증을 거쳐 VERIFIED로 전환한다. 아직 진행 중이면 모니터링을 재개한다. 부분 설치가 확인되면 공식 재개 또는 정리 절차를 선택하고 승인받는다. 동일 설치 명령을 바로 다시 실행하는 것은 실패로 판정한다.

34.17 설치결과서와 운영 인수

보고서에는 계획 버전, 대상 역할, 단계별 상태와 소요시간, 예외 승인, 아티팩트 digest, 검증 결과 및 미해결 이슈를 포함한다. 비밀번호·토큰·개인키·실제 고객 식별정보는 제외하고 접근 제어된 원본 증거와 마스킹된 보고서를 분리한다.

  • 필수 단계 VERIFIED 및 업무 검수 완료
  • 백업·복구, 모니터링, 운영 권한 인계
  • 실패 복구 훈련 및 승인 이력 확보
  • 지원 버전과 실제 설치 BOM 비교

34.18 자동화 수용 기준과 경제성

교육용 사례: 월 12건, 수동 작업 8시간/건, 자동화 후 검토 및 예외 처리 2시간/건이면 월 72시간이 절감된다. 시간당 5만원의 노동시간 가치로 월 360만원이며 운영비 120만원을 차감하면 월 240만원이다. 초기 개발·검증비 2,400만원의 단순 회수기간은 10개월이다. 실제 절감은 인력 재배치, 장애 비용, 예외 발생률을 반영해 측정한다.

수용 시험은 중복 설치 0건, 승인 없는 변경 0건, 연결 단절 후 안전한 상태 복원, 필수 업무 검수 실패 시 인계 차단을 포함한다. 가상 목표이며 실측 제품 성능이 아니다.

공식 참조: Oracle Database · Red Hat · Kubernetes · OpenSSH. 다음 장에서는 설치 자동화 검증 환경과 릴리스 품질 관리 체계를 정리한다.
