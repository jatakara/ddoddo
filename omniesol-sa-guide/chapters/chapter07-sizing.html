7장. Server Sizing Matrix

OmniEsol ERP/UC 인프라 용량은 등록 사용자 수만으로 결정하지 않는다. 동시성, 업무량, 피크 부하, 데이터 증가율과 가용성 요구를 함께 분석한다.

이 장의 계산과 수치는 교육용 가정이다. OmniEsol의 공식 최소·권장 사양이 아니며 실제 구축은 제품 지원 기준과 부하 시험으로 검증해야 한다.

7.1 산정 절차

업무 범위 → 동시 사용자 → 요청량 → CPU·메모리·I/O → HA·성장률 → 부하 시험 → 최종 승인

7.2 필수 입력값

구분확인 사항
사용자전체 계정, 피크 동접, 실제 활동 사용자
업무ERP 모듈, UC 기능, 마감·배치, 외부 연계
성능RPS, p95 응답시간, CPU 사용시간, SQL 대기
데이터DB 크기, 첨부파일, 연간 증가율, 보존 기간
운영RTO/RPO, 백업, 장애 격리, 확장 계획

측정값이 없으면 추정치를 명시하고 PoC와 운영 초기 측정으로 보정한다.
